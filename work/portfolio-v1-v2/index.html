My own website, twice. The first one was made during my master's in web design, when I still presented myself as a graphic designer. Instead of updating it, I rebuilt it from scratch as my work moved towards web and interface design, and that rebuild is the site you are on now.

Version 1. A clean, bright portfolio built around a large name on the home page, a row of featured projects, a short introduction and a contact form. It worked as a showcase, but it spoke as a graphic designer and treated every project the same way, from packaging to illustration.

What changed. By the end of the master's, the work I wanted to be hired for had changed. The site needed to lead with web and UI projects, explain the process behind them and show, not just say, that I can build what I design.

Visit the first website

Rebuilt from scratch. Instead of updating the first site, I started again from a blank file. The website you are on now is the result: designed in Figma and hand-coded in HTML, CSS and JavaScript, with no frameworks or libraries, as a typographic, brutalist system on a six-column grid, set in Rethink Sans, with every size, space and colour defined as a variable.

Interactions as proof. The details do the talking: the name in the hero melts under the cursor, links rewrite themselves on hover, the logo in the footer only appears where the mouse passes, and project images ripple like water. Each one is written from scratch in WebGL or JavaScript.

The first site is still online, so both can be compared side by side. It is the clearest way I have to show how my work has changed: from presenting projects to designing and building the whole experience myself.
